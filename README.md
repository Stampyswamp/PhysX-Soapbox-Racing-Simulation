A C++ physics simulation project developed during my BSc (Hons) Games Computing degree at the University of Lincoln.

Inspired by the Red Bull Soapbox Race, this project explores physics-based vehicle movement and procedural track generation using NVIDIA PhysX. The simulation features downhill racing environments with configurable track sections, collision detection and a custom soapbox vehicle.

Key Features

Procedural Track Generation: Generates track layouts using combinations of ramps, flat sections, left turns and right turns, with randomised dimensions and a configurable seed.

Physics-Based Vehicle: Implements a soapbox vehicle with a chassis and four wheel shapes, using PhysX rigid-body simulation.

Track Construction: Builds track sections from configurable parameters, allowing both predefined and procedurally generated layouts.

Collision Detection: Uses PhysX collision filtering, contact events and trigger callbacks to handle interactions between simulation objects.

Physics Configuration: Configurable materials, mass, damping and collision properties.

Visualisation: Uses a graphics and rendering framework to display the physics simulation.

Technologies Used

Language: C++

Physics Engine: NVIDIA PhysX

Development Environment: Microsoft Visual Studio

Graphics: OpenGL / GLUT

Programming Concepts: Object-oriented programming, procedural generation, rigid-body physics, collision detection and simulation event handling
